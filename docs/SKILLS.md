# Библиотека скиллов

Скилл — это папка с `SKILL.md`: короткое описание видно агенту всегда, а полная инструкция загружается только тогда, когда подходит к задаче. Формат совместим с Hermes и стандартом Agent Skills.

## Установка на сервер клиента

Самый прозрачный способ — скопировать только нужные папки в основной каталог Hermes:

```bash
mkdir -p ~/.hermes/skills/business
cp -R skills/business-daily-brief ~/.hermes/skills/business/
cp -R skills/lead-qualification ~/.hermes/skills/business/
```

Повторите для согласованного набора. Затем начните новую сессию и проверьте:

```bash
hermes skills list
```

Если репозиторий опубликован как Hermes tap, его можно подключить командой `hermes skills tap add ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ`, а затем устанавливать отдельные скиллы. Для приватного GitHub понадобится отдельный токен с минимальным доступом только к этому репозиторию.

## Правило подключения

Наличие скилла не даёт агенту новый технический доступ. Например, `crm-update-safe` описывает порядок безопасного обновления, но записать данные сможет только при наличии отдельно подключённого CRM-инструмента. Для каждой интеграции нужны согласие клиента, отдельный секрет, минимальные права и тестовый контур.

## Как добавлять новый скилл

1. Создайте `skills/<короткое-имя>/SKILL.md`.
2. В frontmatter укажите уникальные `name`, `description`, `version` и теги.
3. Опишите, когда навык применять и когда не применять.
4. Отделите подготовку результата от внешнего действия.
5. Добавьте проверяемый формат результата и критерии завершения.
6. Проверьте навык на реальном обезличенном примере до установки клиенту.

Не делайте один универсальный скилл «для всего бизнеса»: узкие навыки легче проверять, ограничивать и улучшать.

## Открытые внешние наборы

Методологию разработки Superpowers лучше устанавливать из официального репозитория, а не копировать в этот каталог:

```bash
hermes plugins install obra/superpowers --enable
```

После установки начните новую сессию. Перед использованием в production проверьте актуальную лицензию, состав плагина, телеметрию и разрешённые инструменты.

## Сервисные расширения

Генерация изображений, транскрибация, чтение социальных сетей, Datawrapper, Miro, CRM и другие внешние сервисы требуют отдельного технического инструмента или API. Добавляйте соответствующий скилл только вместе с карточкой интеграции: владелец аккаунта, условия коммерческого использования, тип передаваемых данных, лимит расходов, разрешённые действия и способ отключения.
