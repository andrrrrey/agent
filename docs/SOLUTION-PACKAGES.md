# Пакеты решений для клиента

Продавайте не «AI-агента вообще», а конкретный управляемый контур с измеримым результатом.

## 1. Контроль продаж

### Результат

Ежедневная сводка зависших сделок, просроченных задач, потерянных лидов и следующего шага по каждой приоритетной сделке.

### Данные

CRM, правила стадий/SLA, продукт и роли менеджеров. Первая версия только читает CRM.

### Скиллы

`lead-qualification`, `sales-pipeline-control`, `lead-followup-sequence`, `crm-update-safe`, `proposal-builder`, `winback-campaign`, `business-daily-brief`.

### Метрики

Скорость первого ответа, сделки без следующего шага, просрочки, конверсия стадий, цикл сделки, winback-выручка.

## 2. Маркетинговый аналитик

### Результат

Единая воронка от источника до оплаты, выявление потерь и еженедельный список проверяемых гипотез.

### Данные

GA4/Метрика, рекламные расходы, CRM/оплаты, UTM и словарь метрик.

### Скиллы

`marketing-funnel-audit`, `campaign-performance-review`, `customer-journey-analysis`, `weekly-kpi-review`, `chart-builder`, `business-research`.

### Метрики

Стоимость квалифицированного лида/оплаты, конверсия этапов, потерянная выручка, качество атрибуции, скорость подготовки отчёта.

## 3. Контент-конвейер

### Результат

Исследование тем, очередь оригинальных идей, брифы, сценарии, карусели, редакторское согласование и анализ результатов.

### Данные

ICP, продукты, голос бренда, вопросы клиентов, разрешённые конкурентные источники и результаты публикаций.

### Скиллы

`topic-monitor`, `brand-content-engine`, `content-factory`, `short-video-script`, `long-video-producer`, `social-carousel`, `seo-content-pipeline`, `transcript-to-insights`.

### Метрики

Время и стоимость производства, выпуск по плану, полезные действия, лиды/продажи из контента, доля материалов с проверенными источниками.

## 4. Помощник руководителя

### Результат

Утренние и недельные сводки, протоколы встреч, контроль решений, рисков, KPI и открытых вопросов.

### Данные

Календарь, согласованные чаты/документы, задачи и показатели. Запись в системы — только после подтверждения.

### Скиллы

`business-daily-brief`, `meeting-to-actions`, `business-chat-archive`, `weekly-kpi-review`, `incident-triage`, `diagram-builder`.

### Метрики

Время руководителя, просроченные решения, доля задач с владельцем/сроком, скорость подготовки отчёта.

## 5. База знаний и клиентский сервис

### Результат

Ответы с цитатами из внутренних документов, безопасные черновики клиентам, выявление пробелов и предложения обновить инструкции.

### Данные

Политики, продукты, договоры, FAQ и разрешённая история обращений.

### Скиллы

`knowledge-base-answer`, `customer-reply-draft`, `document-intake`, `sop-builder`, `lessons-to-rules`.

### Метрики

Время ответа, точность ссылок, доля эскалаций, число повторных вопросов, объём ручных правок.

## Правило комплектации

Начните с одного пакета и 3–7 скиллов. Сначала read-only отчёт или черновик, затем подтверждённая запись и только после стабильных eval — безопасная автоматизация по расписанию.
