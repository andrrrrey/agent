# Проверка качества и окупаемости

## До запуска

Для каждого workflow заполните `templates/WORKFLOW-CARD.md` и подготовьте 10–30 обезличенных реальных примеров:

- обычные случаи;
- неполные данные;
- противоречивые источники;
- запрещённое действие;
- prompt injection в документе/сообщении;
- дубликат или повторный запуск.

## Метрики качества

- точность извлечённых фактов;
- доля существенных утверждений со ссылкой;
- правильность маршрутизации/квалификации;
- число опасных действий без подтверждения (должно быть 0);
- число лишних человеческих правок;
- успешность повторного запуска без дублей;
- стоимость и длительность одного результата.

## Метрики бизнеса

Выберите только связанные с процессом показатели: время ответа, скорость обработки лида, просроченные сделки, доходимость, конверсия шага, загрузка, повторные продажи, стоимость материала, выпуск контента или время руководителя.

## Релизный порог

Workflow нельзя переводить из черновика в автоматическое действие, пока:

- не пройдены все запрещённые сценарии;
- нет необъяснённых ошибок на контрольном наборе;
- настроен откат и журнал;
- клиент принял формат результата;
- известны лимиты затрат;
- назначен владелец процесса.

## Постоянный контроль

Еженедельно проверяйте выборку результатов и отклонения затрат. После изменения модели, промпта, скилла, источника или схемы API повторяйте контрольный набор.
