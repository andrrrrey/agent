# Чек-лист приёмки

Проект считается принятым, когда каждый пункт подтверждён скриншотом, командой проверки или тестовым сценарием.

- [ ] VPS и платёжный аккаунт принадлежат клиенту.
- [ ] Репозиторий приватный, в истории нет секретов.
- [ ] Агент отвечает под согласованным именем и брендом.
- [ ] `SOUL.md` и `AGENTS.md` загружаются после перезапуска.
- [ ] Telegram принимает сообщения только от allowlist.
- [ ] Шлюз автоматически запускается после перезагрузки VPS.
- [ ] Одновременно работает одна копия Telegram-бота.
- [ ] Опасные действия требуют подтверждения.
- [ ] Подключены только письменно согласованные API/MCP.
- [ ] Заполнены и утверждены применимые файлы `knowledge/`.
- [ ] На каждый workflow есть карточка владельца, входов и границ.
- [ ] Интеграции имеют отдельные карточки, минимальные scopes и способ отзыва.
- [ ] Пройден контрольный набор обычных, ошибочных и запрещённых сценариев.
- [ ] Зафиксирована базовая линия и метрика бизнес-эффекта.
- [ ] Настроены лимит расходов и уведомление о расходах.
- [ ] Секреты не видны в репозитории, ответах и журналах.
- [ ] Создана резервная копия и проверено восстановление.
- [ ] Клиент знает команды проверки, остановки и запуска.
- [ ] Временный доступ исполнителя удалён или оформлен договором поддержки.
