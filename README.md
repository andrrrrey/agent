# Независимый AI-агент для бизнеса

Шаблон проекта для установки персонального AI-агента на сервере клиента. Агент работает круглосуточно, принимает задачи в Telegram и использует только те данные и интеграции, которые письменно согласованы с клиентом.

## Что входит

- оригинальные правила поведения агента (`AGENTS.md`);
- шаблон имени, роли и стиля общения (`templates/SOUL.md`);
- пример переменных окружения без секретов (`.env.example`);
- собственная библиотека бизнес-скиллов (`skills/`);
- шаблоны бизнес-памяти клиента (`knowledge/`);
- карта усиления и интеграций (`docs/POWER-UP-ROADMAP.md`);
- готовые пакеты решений для продажи (`docs/SOLUTION-PACKAGES.md`);
- методика проверки качества и окупаемости (`docs/EVALUATION.md`);
- подробный сценарий установки (`docs/DEPLOYMENT.md`);
- анкета и порядок запуска у клиента (`docs/CLIENT-ONBOARDING.md`);
- правила безопасности и эксплуатации (`docs/SECURITY.md`);
- чек-лист приёмки (`docs/ACCEPTANCE.md`).

## Архитектура

```text
Telegram клиента
       |
       v
Hermes Gateway на VPS клиента
       |
       +-- модель (выбранный клиентом провайдер)
       +-- рабочая папка клиента
       +-- разрешённые клиентом MCP/API
       +-- журналы и резервные копии
```

В репозитории нет закрытых учебных материалов, токенов, клиентских данных и исходного кода Hermes. Hermes устанавливается из официального репозитория и используется по лицензии MIT.

## Быстрый старт

1. Создайте приватный репозиторий из этой папки.
2. Заполните плейсхолдеры в `AGENTS.md` и `templates/SOUL.md`.
3. Пройдите анкету из `docs/CLIENT-ONBOARDING.md` вместе с клиентом.
4. Выполните `docs/DEPLOYMENT.md` сначала на тестовом окружении.
5. Выберите и установите навыки по `docs/SKILLS.md`.
6. Заполните бизнес-память в `knowledge/`.
7. Подключайте системы по `docs/INTEGRATIONS.md`.
8. Проверьте качество по `docs/EVALUATION.md`.
9. Передайте клиенту результат по `docs/ACCEPTANCE.md`.

## Принцип владения

VPS, домен, Telegram-бот, аккаунт модели, ключи и рабочие данные оформляются на клиента. Исполнитель получает отдельный временный доступ и после приёмки удаляет его либо оставляет только по договору поддержки.
